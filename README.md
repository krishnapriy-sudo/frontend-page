# Frontend Internship Assignment – Course Listing Page

This project is a frontend internship assignment demonstrating core frontend development skills using **HTML, CSS, and Vanilla JavaScript**. The project focuses on webpage creation, clean UI structure, and dynamic content rendering.

---

## 📌 Project Description

The assignment consists of two main tasks:

### Task 1: Webpage Creation
- Built a clean and structured webpage using semantic HTML
- Styled the layout using CSS with a responsive grid
- Focused on simple, readable, and user-friendly design

### Task 2: Dynamic Elements
- Implemented dynamic rendering of course cards using JavaScript
- Used JSON data to populate content dynamically
- Added a filter button to display beginner-level courses
